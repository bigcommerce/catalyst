# Codebase map

Where things are in a Catalyst storefront. Paths start at the storefront folder. A fork can move files, so check that a path exists before you rely on it.

| Need                                                    | Where                                                                                                                                                                                                                                                 |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Home page and its data                                  | `app/[locale]/(default)/page.tsx`, `page-data.ts`                                                                                                                                                                                                     |
| Product page and its data                               | `app/[locale]/(default)/product/[slug]/page.tsx`, `page-data.ts`                                                                                                                                                                                      |
| Category, brand, and search pages                       | `app/[locale]/(default)/(faceted)/`                                                                                                                                                                                                                   |
| Cart page                                               | `app/[locale]/(default)/cart/`. It returns the empty state early when there is no cart, so later sections do not render.                                                                                                                              |
| Account pages                                           | `app/[locale]/(default)/account/` (addresses, orders, settings, wishlists; no dashboard page). `proxies/with-auth.ts` sends guests to sign-in only below `/account/`, not for `/account` itself. Data file to copy: `account/settings/page-data.tsx`. |
| Layout, header, footer                                  | `app/[locale]/(default)/layout.tsx`, `components/header/`, `components/footer/`                                                                                                                                                                       |
| Header search (popup with products, categories, brands) | `components/header/_actions/search.ts`, `~/data-transformers/search-results-transformer`, `SearchForm` in `vibes/soul/primitives/navigation/index.tsx`                                                                                                |
| Search filters (categories, brands, price)              | `searchProducts.filters` (for example, `... on CategorySearchFilter`). See `app/[locale]/(default)/(faceted)/fetch-faceted-search.ts`.                                                                                                                |
| Focus ring to copy                                      | `focus-visible:ring-2 focus-visible:ring-[var(--product-card-focus,hsl(var(--primary)))] focus-visible:ring-offset-4` in `vibes/soul/primitives/product-card`                                                                                         |
| Server actions                                          | `_actions/` next to the page that uses them, or `components/<name>/_actions/` for a layout part (for example, `components/header/_actions/`)                                                                                                          |
| UI primitives from packages                             | Radix: accordion, checkbox, dialog, dropdown-menu, navigation-menu, popover, radio-group, select, switch, toggle, tooltip. No combobox library.                                                                                                       |
| Session                                                 | `getSessionCustomerAccessToken` and `isLoggedIn` from `~/auth`                                                                                                                                                                                        |
| Currency                                                | `getPreferredCurrencyCode` from `~/lib/currency`, type `CurrencyCode` from `~/components/header/fragment`                                                                                                                                             |
| Default cache time                                      | `revalidate` from `~/client/revalidate-target` (3600 seconds unless the env sets it)                                                                                                                                                                  |
| Theme tokens and fonts                                  | `globals.css` (colors, sizes, shadows), `app/fonts.ts` (`next/font/google`, hosted locally)                                                                                                                                                           |
| Animations                                              | Keyframes in `tailwind.config.js`. For a marquee, use `animate-scrollLeft` with `--marquee-duration`. Do not add keyframes.                                                                                                                           |
| Badge                                                   | `vibes/soul/primitives/badge`                                                                                                                                                                                                                         |
| Product card query and transform                        | `components/product-card/fragment.ts`, `~/data-transformers/product-card-transformer`                                                                                                                                                                 |
| Price query and transform                               | `client/fragments/pricing.ts`, `~/data-transformers/prices-transformer`                                                                                                                                                                               |
| Price display                                           | `vibes/soul/primitives/price-label`                                                                                                                                                                                                                   |
| Cart writes                                             | `addToOrCreateCart` from `~/lib/cart`                                                                                                                                                                                                                 |
| Add to cart by product ID (action and form to copy)     | `app/[locale]/(default)/compare/_actions/add-to-cart.tsx`, `vibes/soul/primitives/compare-card/add-to-cart-form.tsx`                                                                                                                                  |
| Form fields                                             | `vibes/soul/form/` (checkbox, checkbox-group, input, select, switch, and more)                                                                                                                                                                        |
| Toasts                                                  | `toast` from `@/vibes/soul/primitives/toaster`                                                                                                                                                                                                        |
| YouTube video                                           | `LiteYouTube` and `getYouTubeId` in `vibes/soul/sections/product-detail/`. Data: `Product.videos`.                                                                                                                                                    |
| Content security policy                                 | `lib/content-security-policy.ts`. By default it sets only `base-uri` and `frame-ancestors`.                                                                                                                                                           |
| Streamable and Stream                                   | `@/vibes/soul/lib/streamable`                                                                                                                                                                                                                         |
| Data file to copy (guest and signed-in fetch)           | `app/[locale]/(default)/page-data.ts`                                                                                                                                                                                                                 |
| Shared page request                                     | `page-data.ts` next to the page. Add a fragment from `components/<name>/fragment.ts` to its query. Fragment to copy: `components/featured-products-list/fragment.ts`.                                                                                 |
| Announcement bar                                        | `banner` slot of `vibes/soul/sections/header-section`, rendered by `vibes/soul/primitives/banner`. `components/header` passes no banner by default. Data: `site.content.banners`.                                                                     |
| Merchant HTML                                           | `rewriteWysiwygContentUrls` from `~/data-transformers/html-content-transformer`, then `dangerouslySetInnerHTML` (see the product and blog pages). The function corrects image URLs only. It does not sanitize HTML.                                   |
| Locale and channel                                      | `client/before-request.ts` sends `Accept-Language`. `channels.config.ts` maps locales to channels.                                                                                                                                                    |
| Product rail                                            | `vibes/soul/sections/product-carousel`. `featured-product-carousel` wraps it and always shows an empty state.                                                                                                                                         |
| Cookies                                                 | Server: `cookies()` from `next/headers`. Check consent first (see the consent row).                                                                                                                                                                   |
| Section wrapper, skeleton, buttons                      | `vibes/soul/sections/section-layout`, `vibes/soul/primitives/skeleton`, `button`, `button-link`                                                                                                                                                       |
| Images and links                                        | `Image` from `~/components/image` (its loader fills `{:size}` in a `urlTemplate`), `Link` from `~/components/link`. Lint blocks `next/link`.                                                                                                          |
| Category image                                          | `categoryTree { image }` or `category(entityId) { defaultImage }`. Query both in the first check.                                                                                                                                                     |
| Cookie consent (server, client)                         | `hasConsentFor` in `~/lib/consent-manager/has-consent-for`; `useConsentManager` from `@c15t/nextjs/client` (see `components/consent-manager/start-visit-on-consent.tsx`)                                                                              |
| Analytics events                                        | `lib/analytics/`                                                                                                                                                                                                                                      |
| Text                                                    | `messages/en.json`. Other locales fall back to it, so add new keys to `en.json` only.                                                                                                                                                                 |
